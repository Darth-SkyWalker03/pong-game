# 🎮 Pong Game\n\nA modern recreation of the classic Pong game built with HTML, CSS, and JavaScript. Play against an AI opponent with realistic physics and collision detection.\n\n## 🚀 Play Now\n\n**[Click here to play the game](https://Darth-SkyWalker03.github.io/pong-game/)**\n\n## 🎯 How to Play\n\n### Controls\n- **Mouse**: Move your paddle by moving your mouse up and down\n- **Keyboard**: Use Arrow Keys (↑ Up / ↓ Down) to move your paddle\n- **Start/Pause**: Click the \"Start Game\" button to begin or pause\n- **Reset**: Click \"Reset Score\" to clear scores and restart\n\n### Gameplay\n- You control the **left paddle** (green)\n- The **computer** controls the **right paddle** (magenta)\n- The ball bounces around the arena\n- Score a point when the ball passes your opponent\n- The ball speed increases slightly with each paddle hit\n- The ball's direction changes based on where it hits the paddle\n\n## 🛠️ Features\n\n✅ **Mouse & Keyboard Controls** - Multiple input methods for your preference  \n✅ **AI Opponent** - Challenging computer player with smart movement  \n✅ **Physics System** - Realistic ball movement with acceleration  \n✅ **Collision Detection** - Accurate paddle and wall collisions  \n✅ **Real-time Scoreboard** - Track your progress against the AI  \n✅ **Responsive Design** - Works on different screen sizes  \n✅ **Retro Neon Aesthetic** - Glowing effects and modern styling  \n\n## 📁 Files\n\n- **index.html** - Game structure and layout\n- **styles.css** - Styling and animations\n- **script.js** - Game logic and physics engine\n- **README.md** - This file\n\n## 💻 Local Setup\n\nIf you want to run it locally:\n\n1. Clone the repository:\n```bash\ngit clone https://github.com/Darth-SkyWalker03/pong-game.git\ncd pong-game\n```\n\n2. Open `index.html` in your web browser\n\n## 🎨 Customization\n\nYou can easily customize the game by editing `script.js`:\n\n- **Ball Speed**: Change the `ball.speed` variable\n- **Paddle Speed**: Modify `paddleSpeed`\n- **AI Difficulty**: Adjust the `difficulty` variable in `computer.updateAI()`\n- **Colors**: Update the `fillStyle` colors in the draw functions\n\n## 🎓 Learning Resources\n\nThis project demonstrates:\n- HTML5 Canvas API\n- Game loop implementation\n- Collision detection algorithms\n- AI pathfinding logic\n- Event handling (keyboard & mouse)\n- CSS animations and gradients\n\n## 🤝 Contributing\n\nFeel free to fork, modify, and improve the game!\n\n## 📝 License\n\nFree to use and modify.\n\n---\n\n**Enjoy the game! 🎮**\n
